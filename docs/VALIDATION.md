## 尚需日常 Chrome 验收

`HEADED=1 npm run test:browser` 的系统窗口焦点检查出现过成功，也出现过超时。超时时测试浏览器所有窗口都返回 `focused: false`，未满足“测试浏览器处于前台”的条件，因此不将有界面全套验证记为通过。无界面测试仅证明原标签被选中、正确窗口收到激活请求，以及重复页被关闭。

安装后建议验收：在窗口 A 打开一个页面并输入未保存内容，在窗口 B 再打开同一网址，确认新页关闭、回到窗口 A、原输入保留。再分别验证参数不同的两个任务保持独立，以及“暂停”后允许重复打开。
